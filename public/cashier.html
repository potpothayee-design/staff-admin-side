New student account

Only the school cashier can create student accounts. Check the student's school ID card first.

Format: 04-23-0006 (dashes are added automatically)

How it works

  1. The student shows their school ID card.
  2. Create the account. It starts with ₱1,000.00.
  3. Give the student the slip with the temporary password (print it or let them take a photo).
  4. At first login the student must set their own password.

Forgot password?

Go to Wallet Top-Up, find the student and tap Reset password. They get a new temporary password and must set a new one at login.
